Política de Privacidad y Eliminación de Datos — Sistema Gonbel OS

Política de Privacidad

Gonbel Imports ("nosotros") opera un sistema interno de gestión llamado Gonbel OS, que utiliza la API de WhatsApp Business (Meta) para comunicarse con clientes de Gonbel Imports en Ciudad del Este, Paraguay.

Los datos que procesamos a través de esta integración incluyen: número de teléfono de WhatsApp, nombre de perfil, y el contenido de los mensajes (texto, fotos, videos, audios o documentos) que el cliente envía voluntariamente para solicitar cotizaciones o hacer seguimiento de un pedido de autopartes.

  • No vendemos ni compartimos esta información con terceros ajenos a la operación de Gonbel Imports.
  • Los datos se usan exclusivamente para atender consultas, preparar presupuestos y dar seguimiento a pedidos.
  • El acceso a esta información está limitado al personal de Gonbel Imports (Lucas González y Joaquín).
  • Los datos se almacenan de forma segura en nuestra infraestructura (Supabase) con acceso restringido.

Para cualquier consulta sobre privacidad, escribinos a gonbel-imp@hotmail.com.

Eliminación de Datos de Usuario

Si querés que eliminemos tus datos personales (mensajes, número de contacto, historial de conversación) de nuestro sistema, escribinos a gonbel-imp@hotmail.com indicando el número de WhatsApp asociado, o mandanos un mensaje de WhatsApp con la palabra "ELIMINAR MIS DATOS".

Procesamos toda solicitud de eliminación dentro de un plazo de 30 días.
